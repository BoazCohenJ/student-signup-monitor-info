Privacy Policy

Student Signup Monitor is a personal tool used only by its owner, on the owner's own Google accounts.

What data it accesses

  • Gmail: it reads signup notification emails and marks processed emails as read.
  • Google Contacts: it creates contacts with the name and phone number found in those emails.

How the data is used

The data is used only to create those contacts. It is processed on a private server owned by the tool's owner, and is not sold, shared with third parties, or used for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
